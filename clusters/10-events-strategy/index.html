Product doc · Productized Event Loop

Capture-collect-convert-close as one tool, not 4 manual steps. Goal: Tony's team operates an event without 6 spreadsheets.

The opportunity

Today the event loop is: print QR → manually transcribe attendees → manually pull brand mentions from speech-booth videos → email blast within 12 hours → manual brand-by-brand follow-up. Multiple deals close from this each event. Productizing it doesn't change what works; it lets us run more events with the same team.

v1 scope

  • Event creation: admin sets up event, generates per-event QR + microsite ("benable.com/dallas25").
  • Attendee capture: QR → fast 3-question intake (name, IG, top 3 brands). Auto-creates Benable account.
  • Speech booth uploads: iPad app records, tags creator, optionally transcribes brand mentions.
  • Brand-mention digest: live dashboard during event of all brand names captured.
  • Post-event automation: 12hr "your brand came up" email to all mentioned brands; 48hr flash discount link; 2-day "thanks for coming" email to creators with one CTA.
  • Hand-off to brand portal: brands that click flash-discount go to a pre-filled portal signup with attribution.

Out of scope

  • Creator-led meetups (ID 45). Defer until we've productized our own events.
  • Brand-owner referral program (ID 130). Separate spec.

Success metrics

  • Time from event end to "your brand came up" email: ≤ 12 hours, no manual transcription.
  • ≥ 50 brand-portal leads per event (Tony's stated target).
  • Sienna's prep time per event drops by ≥ 50%.
